## How to participate

**Open an issue.** That is the way to suggest a feature, report a bug, or ask
a question. Rafael reads every issue and decides what to implement. There is
no obligation that a request will be accepted or scheduled.

Use the GitHub mirror:

- Issues: <https://github.com/e9li/zapusk/issues>
- Canonical source: <https://git.e9li.com/e9li/zapusk>

Please do **not** send pull requests or patches. The GitHub repository is a
read-only mirror for browsing and issues. We will close PRs without merging
them. If you have a concrete idea, describe it in an issue; if it is taken
up, Rafael implements it.

## A useful issue

Include as much of this as you can:

- What you expected, and what happened instead
- Steps to reproduce
- `zapusk --version` and your OS
- Relevant bits of `~/.config/zapusk/config.toml` (redact secrets)
- For TUI problems: terminal app and a screenshot if it helps

One topic per issue. Search existing issues first.

## Security

Do not file a public issue with a working exploit. Open a GitHub issue that
describes the impact only (no PoC), or contact Rafael via e9li GmbH, and wait
for a reply before publishing details.
